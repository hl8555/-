# 성인 사회정서역량 테스트

성인 사회정서역량 척도(오은혜, 최윤정, 신태섭, 2022)를 기반으로 한 온라인 설문 및 통계 사이트입니다.

## 기능

- **사용자**: 소속·이름 입력 → 10문항 5점 척도 응답 → 본인 합산 점수(총점/50점) 확인
- **관리자**: 암호(`1206`) 입력 후 통계 확인
  - 전체 응답자 수, 총점 평균
  - 문항별 평균 점수 그래프 및 척도별 응답 분포
  - 응답자별 개별 총점 목록 (개별 문항 선택값은 표시하지 않음)

## 점수 기준

| 응답 | 점수 |
| --- | --- |
| 매우 그렇다 | 5 |
| 그렇다 | 4 |
| 보통이다 | 3 |
| 그렇지 않다 | 2 |
| 전혀 그렇지 않다 | 1 |

10문항 × 최대 5점 = 총점 50점 만점.

## 실행 방법

별도의 의존성 설치가 필요 없습니다. Node.js 18 이상이면 바로 실행됩니다.

```bash
npm start
```

또는

```bash
node server.js
```

실행 후 브라우저에서 접속:

- 테스트 화면: <http://localhost:3000>
- 관리자 화면: <http://localhost:3000/admin.html> (암호 `1206`)

포트를 바꾸려면 `PORT` 환경변수를 지정합니다: `PORT=8080 node server.js`

## 데이터 저장

응답은 `data/responses.json` 파일에 저장됩니다. 이 폴더는 버전 관리에서 제외됩니다.

## 관리자 암호 / 문항 변경

- 암호는 `server.js`의 `ADMIN_PASSWORD` 값을 수정합니다.
- 문항은 `server.js`의 `QUESTIONS` 배열을 수정하면 화면·통계에 자동 반영됩니다.
